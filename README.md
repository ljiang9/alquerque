# alquerque 阿爾克棋

古老的跳吃棋（约公元前 1400 年古埃及/中东起源），西洋跳棋（checkers/draughts）
的前身。纯 Python 标准库实现。

## 玩法

- **棋盘**：5×5 点阵。横竖线全连；斜线只画在 `(行+列)` 为偶数的格子里，
  形成贯穿棋盘的长斜线（与传统 Alquerque 棋盘一致）。
- **布子**：双方各 12 子。黑方占第 0、1 行全部，外加 `(2,0)`、`(2,1)`；
  白方占第 3、4 行全部，外加 `(2,3)`、`(2,4)`；`(2,2)` 空。
  （标准开局：每方占靠近自己的两行 + 中央行自己一侧的两个点；白方先手。）
- **走子**：沿线走一格到空点。
- **吃子**：跳过相邻敌子落到其后空点（必须沿线）。
  - **有吃必吃**：有吃子路线时只能吃子。
  - **多吃优先**：多条吃子路线时，必须选吃子数最多的路线。
  - 同一子一回合内可连跳。
- **胜负**：吃光对方，或对方轮到走时无棋可走，即胜。
  400 半回合未分胜负判和棋。

## 用法

```bash
python3 -m alquerque            # 人机对战（你是白方先手）
python3 -m alquerque --auto --games 10 --seed 42   # AI 对 AI 演示
python3 -m alquerque --auto --games 10 --verbose   # 打印每局
```

走子输入坐标如 `c3-d4`（列 a–e，行 1–5，行 1 在最下方）；
多跳连写如 `c3-e5-c5`；`q` 退出。

## 设计取舍

- 吃子路线用回溯法完整枚举（含提前停下、被吃子不可重复跳过），
  再按"吃子数最多"过滤——符合经典规则。
- AI 为 1 步贪心（子力差×100 + 推进度），吃子回合按规则随机选一条
  最多吃子路线。`--seed` 可复现。
- `--auto` 实测：10 局通常在几秒内结束（见下）。

## 诚实局限

- AI 只是 1 步贪心，不做深层搜索；有吃必吃规则下贪心对局往往 20 多个半回合就分胜负，
  残局偶尔互绕撞 400 半回合上限判和棋。熟悉规则的人类通常能赢。
- 未实现 R. C. Bell 的补充规则（禁后退、禁重走、到底线只能吃子等）；以 Alfonso X《博弈之书》
  的基础规则为准，README 已如实说明。
- 文本回合制界面，无图形/存档/悔棋；Python 3.10+，纯标准库。
